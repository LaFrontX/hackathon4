Android приложение
• Стек: Kotlin, Jetpack Compose, Material3, MVVM, Retrofit, DataStore, Navigation Compose.
• Авторизация: Вход по номеру телефона. Bearer-токен сохраняется локально в DataStore. Приложение автоматически проверяет сессию при запуске: при наличии токена открывается главный экран, при отсутствии — экран логина. Токен автоматически добавляется в заголовок Authorization ко всем запросам.
• Баланс и оплата: Динамическое отображение баланса, загружаемое с сервера. Кнопка «Пополнить» отправляет запрос на бэкенд. При успешной операции баланс обновляется в реальном времени, интерфейс показывает уведомление об успехе.
• Deep Links: Поддержка ссылок transportapp://payment/{сумма}. Переход по ссылке мгновенно открывает экран оплаты с предзаполненной суммой, работает как из внешнего браузера, так и из системных уведомлений.
• Интерфейс и UX: Темная тема Material3 (фон #222222, акцент #17C0C3). Вместо крутилок загрузки используются Shimmer-скелетоны. Реализованы плавные анимации смены состояний (Loading/Success/Error), Pull-to-Refresh на истории поездок и тактильный отклик (вибрация) при нажатии кнопок и успешных действиях.
• Архитектура: Чистое разделение на слои (Data/Domain/UI). Состояния экранов управляются через StateFlow. Реализована обработка сетевых ошибок и автоматический редирект на экран входа при истечении сессии. Приложение полностью адаптировано под работу с REST API.
Устройство: API 24 для эмуляции
